Tier 1 • Entry Level 0 - 2 Years Exp

IT Support / Help Desk Technician

The foundational stepping stone in IT operations. Focuses on frontline technical troubleshooting, end-user hardware/software support, and ticket queue management.

Main Responsibilities

  • Triage end-user incidents via ticketing systems (e.g., ServiceNow, Jira).
  • Deploy and configure OS images on workstation hardware.
  • Manage basic Active Directory user resets and password unlocks.
  • Troubleshoot local peripheral, printer, and LAN connectivity issues.

Required Skills & Prep

Customer Service Windows 10/11 Hardware Diagnostics CompTIA A+
Tier 2 • Intermediate 2 - 5 Years Exp

System Administrator

The core engine of IT maintenance. Responsible for server health, network service availability, user directory hierarchies, data backups, and environment stability.

Main Responsibilities

  • Maintain Active Directory, Domain Controllers, and Group Policies.
  • Manage Linux (Ubuntu/RHEL) and Windows Server instances.
  • Configure hypervisors (VMware vSphere, Proxmox VE).
  • Implement backup retention, patching, and disaster recovery procedures.

Required Skills & Prep

PowerShell / Bash Networking (TCP/IP) Virtualization CompTIA Network+/Security+
Tier 3 • Advanced 5+ Years Exp

Senior Systems Engineer / IT Infrastructure Manager

Leadership and strategic architecture role. Focuses on hybrid-cloud integration, automation pipelines, high-availability clusters, and enterprise security strategy.

Main Responsibilities

  • Architect multi-region cloud infrastructures (AWS / Azure).
  • Implement Infrastructure as Code (Terraform, Ansible).
  • Establish zero-trust security postures and compliance audits.
  • Lead disaster recovery plans and manage infrastructure budgets.

Required Skills & Prep

AWS / Azure Solutions Ansible / Terraform High Availability RHCSA / AWS Certified
Core Competencies

Essential Skills & Qualifications

Five core pillars required to establish and maintain enterprise-grade computer systems.

1. Operating System Administration

Proficiency in both Windows Server (Active Directory, IIS, NTFS) and Linux distributions (Ubuntu, RHEL, CLI navigation, service daemons).

Why It's Vital:

Servers run applications. Without deep OS understanding, configuring, updating, and securing servers becomes unmanageable.

2. Networking Fundamentals

Mastery of TCP/IP stack, Subnetting, VLAN segregation, DNS name resolution, DHCP allocations, routing protocols, and firewall rulesets.

Why It's Vital:

Servers must communicate securely. Network issues frequently manifest as system faults; sysadmins must isolate network vs OS bugs.

3. Troubleshooting & Diagnostics

Methodical isolate-and-conquer problem-solving. Analyzing system logs (Event Viewer, syslog), performance metrics, and network packet captures.

Why It's Vital:

Downtime costs revenue. The speed and accuracy with which a SysAdmin restores services directly safeguards business continuity.

4. Security Fundamentals & Identity

Understanding Role-Based Access Control (RBAC), Least Privilege policies, MFA implementation, SSL/TLS certificates, and patch management protocols.

Why It's Vital:

Misconfigurations lead to data breaches. Systems must be hardened continuously against external threats and unauthorized entry.

5. Scripting & Automation

Writing shell scripts (PowerShell, Bash, Python) to automate repetitive administrative tasks, bulk user provisioning, and maintenance routines.

Why It's Vital:

Automation replaces human error and scales infrastructure. A single script can configure 100 servers in minutes instead of days.
